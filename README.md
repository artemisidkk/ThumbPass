# ThumbPass
Have you ever not trusted a password saving website? Well why not try putting all the saved passwords onto your hardrive in a compiled application!

With this application, you can access your passwords for specific domains off of one thumb drive, so it looks like your standard password saving operation on a browser or company, but it functions like a notepad in the sense that it's only on a drive instead of the cloud

pros: 
- no need for potential 3rd parties scalping your data and selling it for money
- application is locked behind a password so even if someone else steals your drive, they can't access the passwords


cons:
- only on the thumb drive, so if you lose the drive, you lose the passwords, unless you have a backup somewhere
- no autofill (yet)
